# 教务大屏 - 数据维度设计

## 筛选条件

| 筛选维度 | 默认值   | 可选范围                                                                                 |
| -------- | -------- | ---------------------------------------------------------------------------------------- |
| 年级     | 全部     | 全部、一年级、二年级、三年级、四年级、五年级、六年级、初一、初二、初三、高一、高二、高三 |
| 时间段   | 近一个月 | 近一个月、近六个月、近一年、全部数据、自定义时段                                         |
| 学科     | 全部     | 全部、语文、数学、英语                                                                   |

> **说明**：
>
> - **年级筛选**：仅影响基础数据（教师、学生、班级数量），其他教学数据按时段统计，不按年级区分
> - **时间段筛选**：影响教学资源、课堂教学、作业数据、学情分析等动态数据，按所选时段内的数据统计
> - **学科筛选**：影响教学资源建设板块的资源卡片显示：
>   - 全部/英语：显示全部11个资源卡片
>   - 语文：显示教案、课件、学案、活动、趣味抽奖、随堂测、听写、智能体（8个）
>   - 数学：显示教案、课件、学案、活动、趣味抽奖、随堂测、智能体（7个）

## 呈现形式

根据数据类型选择合适的可视化方式：

| 数据类型            | 呈现形式                   | 适用场景                                 |
| ------------------- | -------------------------- | ---------------------------------------- |
| **数字卡片**  | 大字号数字 + 单位          | 单一汇总指标（总数、比率）               |
| **数据表格**  | 列排序、分页、年级分组折叠 | 明细数据（班级维度、多项目对比）         |
| **柱状图**    | 垂直/水平柱形              | 单维度对比（班级vs班级、单学科班级对比） |
| **词云**      | 字体大小表示权重           | 薄弱知识点突出（知识点掌握度分布）        |

### 各板块呈现形式明细

| 板块                   | 层级/数据项                      | 呈现形式                             |
| ---------------------- | -------------------------------- | ------------------------------------ |
| **基础数据概览** | 教师/学生/班级总数               | 数字卡片                             |
| **教学资源建设** | 校本资源库（静态数据）           | 数字卡片                             |
|                        | 时段内新增（动态数据）           | 数字卡片                             |
| **课堂教学**     | 使用次数、得分率明细             | 数据表格                             |
| **作业数据**     | 整体汇总（总数、提交率、得分率） | 数字卡片                             |
|                        | 班级维度明细                     | 数据表格（支持排序、分页、年级折叠） |
| **学情分析**     | 知识点掌握度分布                 | 词云（掌握越低越大）               |

## 教学资源建设

| ------------ | ----------------------------------- |
| 教案数量     | 校本资源库中的教案总数              |
| 课件数量     | 校本资源库中的课件总数              |
| 学案数量     | 校本资源库中的学案总数              |
| 活动数量     | 校本资源库中的模板活动+AI活动总数   |
| 趣味抽奖数量 | 校本资源库中的趣味抽奖活动总数      |
| 随堂测数量   | 校本资源库中的AI生成测试题总数      |
| 听写任务数量 | 校本资源库中的听写任务总数          |
| 智能体数量   | 校本资源库中已创建/添加的智能体总数 |
| 单词评测数量 | 校本资源库中的英语单词评测总数      |
| 对话评测数量 | 校本资源库中的英语对话评测总数      |
| 场景对话数量 | 校本资源库中的英语场景对话总数      |
| 校本资源总计 | 以上各类资源的累计总数              |

| 数据项         | 说明                            |
| -------------- | ------------------------------- |

| 新增课件数     | 时段内新建的课件数量            |
| 新增学案数     | 时段内新建的学案数量            |

| 新增趣味抽奖数 | 时段内新建的趣味抽奖数量        |
| 新增随堂测数   | 时段内新建的随堂测数量          |
| 新增听写任务数 | 时段内新建的听写任务数量        |
| 新增智能体数   | 时段内新建/添加的智能体数量     |
| 新增单词评测数 | 时段内新建的单词评测数量        |
| 新增对话评测数 | 时段内新建的对话评测数量        |

## 课堂教学

| -------------- | -------------------------------- | ---------------- | ------------------ |

## 作业数据

统计在所选时间段和学科范围内的作业布置与完成情况。

### 整体数据

| 数据项       | 说明                                   |
| ------------ | -------------------------------------- |
| 作业布置总数 | 所选学科布置的作业总份数               |
| 平均提交率   | 所选学科所有作业的平均提交率（百分比） |
| 平均得分率   | 所选学科所有作业的平均得分率（百分比） |

### 班级维度数据

根据筛选条件展示所选年级范围内的班级作业数据：

| 筛选条件           | 班级维度展示                                                 |
| ------------------ | ------------------------------------------------------------ |
| **多学科**   | 每个班级的多学科**汇总得分率**（等权平均或按课时加权） |
| **单学科**   | 每个班级在该学科的**单独得分率**                       |
| **年级范围** | 仅显示所选年级内的所有班级                                   |

示例表格（多学科 + 一年级）：

| 班级      | 作业布置数 | 平均提交率 | 平均得分率 |
| --------- | ---------- | ---------- | ---------- |
| 一年级1班 | 12         | 95%        | 82%        |
| 一年级2班 | 11         | 92%        | 79%        |
| 一年级3班 | 13         | 97%        | 85%        |

> **跨年级情况**：选择全部年级时，按年级分组展示所有班级，支持展开/折叠年级

## 学情分析

统计在所选时间段内的学生学习情况，反映教学质量。

### 知识点掌握度

采用**词云**方式展示所有知识点的掌握情况：

#### 呈现形式

```
┌────────────────────────────────────────┐
│         知识点掌握度分布（词云）          │
│                                          │
│  [分数乘法]  [文言文]   [英语语法]        │
│     [应用题]   [作文写作]  [词汇积累]    │
│  [几何证明]  [函数图像]    [口算能力]    │
│       [阅读理解]   [听力训练]            │
│                                          │
├────────────────────────────────────────┤
│  ● 薄弱(<60%)  ● 一般(60-80%)  ● 掌握(>80%) │
└────────────────────────────────────────┘
```

#### 设计规则

| 规则 | 说明 |
|------|------|
| **词云大小** | 掌握度越低 → value 越大 → 词越大（薄弱知识点更突出） |
| **词云颜色** | 薄弱区红色，一般区橙色，掌握区绿色 |
| **交互** | 鼠标悬停显示知识点名称和掌握度百分比 |
