## 功能概述

将课堂录音/视频自动转成带角色标注的文字稿，并进一步分析课堂中涉及的核心素养表现，便于教师查看课堂对素养目标的落实情况。

---

## 实现步骤

### 步骤19：核心素养分析

#### 19.1 功能描述

**做什么**：基于学科类型和课堂对话内容，识别课堂中涉及到的核心素养，并按素养卡片形式输出结果。

本功能用于回答以下问题：

1. 这节课涉及到了哪些核心素养
2. 每个核心素养在课堂中是如何体现的
3. 对应的教学方法、师生对话和教学建议分别是什么

**核心素养范围**：

- 英语：语言能力、思维品质、文化意识、学习能力
- 语文：语言建构与运用、思维发展与提升、审美鉴赏与创造、文化传承与理解
- 数学：数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析

#### 19.2 输入数据说明

输入包含两部分：

1. `subject`：学科名称，用于确定本次分析适用的核心素养体系
2. `transcript`：课堂对话内容，不包含 words 字段，只保留角色标注后的文本内容

#### 19.3 处理流程

```
学科名称 + 课堂对话内容（去掉 words）
    ↓
程序将学科与课堂对话同时传给模型（一次调用）
    ↓
模型判断课堂中涉及到哪些核心素养
    ↓
输出核心素养数组，每个元素对应一个素养卡片
```

#### 19.4 AI 识别规则

本步骤完全由模型输出，具体约束以提示词为准。

#### 19.5 输出数据结构（AI 生成）

**JSON 结构示例**：

```json
{
  "core_competency_content": [
    {
      "competency_name": "语言建构与运用",
      "summary": "通过朗读与意象分析，学生能用准确语言描述诗歌画面，并理解诗句表达效果。",
      "teaching_method": "教师引导学生朗诵、圈画关键词，并通过提问促使学生用自己的话复述诗意。",
      "teacher_student_dialogue": "教师：这句诗写出了怎样的画面？学生：像一幅月夜图，画面很静，也很美。",
      "teaching_suggestion": "可以增加学生仿写或口头复述环节，进一步提升语言表达与组织能力。"
    },
    {
      "competency_name": "文化传承与理解",
      "summary": "课堂中借助典故和文化意象的讲解，帮助学生理解诗歌背后的传统文化内涵。",
      "teaching_method": "教师结合诗句补充文化背景，并引导学生联系意象理解古典诗歌的文化表达。",
      "teacher_student_dialogue": "教师：鸿雁在诗里有什么文化意味？学生：它常和传递思念、寄托情感联系在一起。",
      "teaching_suggestion": "可以补充更多相关典故或同类诗篇，帮助学生形成更完整的文化理解链条。"
    }
  ]
}
```

**字段说明**：

| 字段 | 类型 | 来源 | 说明 |
| ----- | ----- | ----- | ----- |
| core_competency_content | array | AI 模型生成 | 按核心素养组织输出的数组 |
| competency_name | string | 固定素养名称 | 核心素养名称，必须使用对应学科的固定名称 |
| summary | string | AI 模型生成 | 一句话说明该素养在课堂中的体现 |
| teaching_method | string | AI 模型生成 | 课堂中与该素养相关的教学方法 |
| teacher_student_dialogue | string | AI 模型生成 | 能体现该素养的师生对话片段 |
| teaching_suggestion | string | AI 模型生成 | 针对该素养落实情况的教学建议 |

#### 19.6 AI 提示词

```
你是一个专业的教学分析助手。

【核心任务】
根据学科名称和课堂对话内容，判断课堂中涉及到了哪些核心素养，并按素养卡片形式输出结果。

【输入数据说明】
输入包含两部分：

1. subject：学科名称，用于确定适用的核心素养体系
2. transcript：课堂对话内容

【学科素养体系】
请根据 subject 选择对应的固定素养名称：
- 英语：语言能力、思维品质、文化意识、学习能力
- 语文：语言建构与运用、思维发展与提升、审美鉴赏与创造、文化传承与理解
- 数学：数学抽象、逻辑推理、数学建模、直观想象、数学运算、数据分析

【输出格式】（严格遵守）
{
  "core_competency_content": [
    {
      "competency_name": "核心素养名称",
      "summary": "一句话说明",
      "teaching_method": "教学方法",
      "teacher_student_dialogue": "师生对话",
      "teaching_suggestion": "教学建议"
    }
  ]
}

【识别规则】
1. 先根据 subject 确定对应的核心素养体系，再结合课堂对话进行分析
2. 只输出课堂中实际体现出来的核心素养，不要输出未体现的素养
3. 素养名称必须使用固定名称，不得改写或自造
4. summary、teaching_method、teacher_student_dialogue、teaching_suggestion 四个字段都控制在 10~100 字
5. teacher_student_dialogue 必须来自课堂对话内容的真实提炼，不得编造
6. teaching_suggestion 必须具体可操作，避免空话
7. 若课堂中某个素养没有明显体现，则不输出该项
8. 不要输出除 JSON 外的任何内容
```

#### 19.7 AI 分析模板（前端展示）
```
本节课教学内容，共涉及核心素养{{core_competency_count}}个，分别为{{core_competency_names}}。
```

**说明**：`core_competency_count` 对应 JSON 中 `core_competency_content` 数组的长度，`core_competency_names` 对应数组中每个 `competency_name` 的拼接结果。
