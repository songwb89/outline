为承接教师端试用意向收集，并支持运营侧统一查看和跟进申请数据，本次需求新增“申请试用”入口及对应的申请管理能力。

| 1   | 运营端 | 业务数据板块 | 新增菜单"申请管理"，展示申请列表及申请详情 |

## 2. 增加微信扫码登录和工作场景选择等

### 2.1 背景与问题说明

当前教师在教室大屏、教学一体机等课堂环境中登录系统时，仍主要依赖账号密码输入方式，存在以下问题：

1. 教室场景下直接在大屏或公共设备上输入账号密码，存在密码暴露风险，安全性不足；
2. 课堂开始前或授课过程中手动输入账号密码步骤较多，操作繁琐，影响授课效率；
3. 教师进入系统后默认看到完整功能导航，但课堂授课场景下实际只需要授课相关功能，其他备课、管理类功能在教室内展示不合适，容易造成干扰；
4. 当前登录页缺少对账号信息的便捷记忆能力，教师在个人常用设备上重复登录时仍需反复输入账号和密码，使用体验不够顺畅。

基于以上问题，本次改造需围绕教师登录与课堂使用场景进行优化：通过微信扫码登录降低密码输入风险与登录操作成本；通过工作场景选择区分“课堂授课”与“日常备课”两类使用场景；通过个人中心补充微信绑定状态管理能力，方便教师后续维护绑定关系；通过记住密码能力提升教师在个人常用设备上的重复登录效率。

### 2.2 需求概述

本次登录改造围绕教师登录链路做四项优化：

1. 新增微信扫码登录入口，支持教师通过扫码完成登录或进入绑定流程；
2. 新增工作场景选择，在登录成功后引导用户选择进入“课堂授课”或“日常备课”场景；
3. 新增个人中心微信绑定状态管理，支持教师在个人中心扫码绑定微信与密码校验解绑微信；
4. 新增“记住密码”能力，支持教师在常用设备登录成功后保存账号和密码，并在后续进入登录页时自动回填。

---

### 2.3 微信扫码登录

#### 功能说明

在原有账号密码登录基础上，新增“微信扫码登录”方式，作为并列登录入口展示。用户可切换至微信扫码页签，通过扫码完成登录流程。

[微信登录功能 / 网站应用微信登录开发指南](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)

#### 交互说明


| #   | 交互项     | 说明                                                     |
| --- | ------- | ------------------------------------------------------ |
| 1   | 登录方式切换  | 登录页提供“账号登录”和“微信登录”两个页签，用户可自由切换                         |
| 2   | 扫码展示    | 切换到微信登录后，页面展示微信二维码、扫码说明及辅助提示                           |
| 3   | 账号状态区分  | 微信扫码登录需覆盖“账号已绑定”和“账号未绑定”两种状态，以分别进入登录成功或账号绑定流程          |
| 4   | 已绑定账号流程 | 当微信账号已绑定系统账号时，扫码后直接登录成功，并提示“登录成功，请选择工作场景”，随后弹出工作场景选择弹窗 |
| 5   | 未绑定账号流程 | 当微信账号未绑定系统账号时，扫码后进入账号绑定流程，完成绑定后提示“账号绑定成功，请选择工作场景。”     |


#### 账号绑定表单说明


| #   | 表单项  | 说明                                  |
| --- | ---- | ----------------------------------- |
| 1   | 账号输入 | 用户需输入系统账号，用于完成微信账号与系统账号绑定           |
| 2   | 密码输入 | 用户需输入系统账号对应密码，用于校验账号身份              |
| 3   | 校验规则 | 账号、密码的填写规则、非空校验、错误提示文案与账号密码登录界面保持一致 |
| 4   | 账号匹配 | 仅当账号和密码校验通过时，才允许完成微信账号绑定            |


### 2.4 工作场景选择

#### 功能说明

用户在登录成功后，不直接进入单一首页，而是先弹出“工作场景”选择弹窗，引导用户根据当前任务进入对应场景。

#### 场景选项说明


| #   | 场景名称 | 场景说明                   |
| --- | ---- | ---------------------- |
| 1   | 课堂授课 | 用于课堂中进行课件讲授、开启活动等教学操作  |
| 2   | 日常备课 | 用于创建备课资源、布置作业等日常教学准备工作 |


#### 交互规则


| #   | 规则项  | 规则说明                                               |
| --- | ---- | -------------------------------------------------- |
| 1   | 触发时机 | 用户登录成功后触发，包括账号密码登录成功、微信已绑定账号扫码成功、账号绑定成功三种情况        |
| 2   | 弹窗标题 | 弹窗标题统一为“请选择工作场景”                                   |
| 3   | 成功提示 | 登录成功提示统一为“登录成功，请选择工作场景”；绑定成功提示统一为“账号绑定成功，请选择工作场景。” |
| 4   | 场景跳转 | 用户选择“课堂授课”后进入授课场景；选择“日常备课”后进入首页                    |
| 5   | 场景独立 | 两个工作场景作为登录后的首次分流入口，便于匹配不同教学任务                      |


#### 页面改造说明


| #   | 页面/模块   | 改造内容                             |
| --- | ------- | -------------------------------- |
| 1   | 登录页     | 新增微信登录页签、扫码区域，并支持已绑定/未绑定两类账号状态流转 |
| 2   | 绑定弹窗    | 新增扫码未绑定账号后的账号绑定流程承接              |
| 3   | 登录后弹窗   | 新增“工作场景”选择弹窗，承接登录成功后的场景分流        |
| 4   | 授课场景导航栏 | 进入课堂授课后，导航栏不再显示导航菜单和可用额度         |
| 5   | 个人中心    | 新增微信绑定状态展示，并支持扫码绑定微信、密码校验解绑微信    |
| 6   | 登录页     | 新增“记住密码”勾选能力，支持登录成功后保存账号密码并自动回填  |


### 2.5 记住密码

#### 功能说明

在账号密码登录场景下，登录页新增“记住密码”勾选项，支持教师在个人常用设备登录成功后保存账号和密码信息，并在后续进入登录页时自动回填，减少重复输入成本。

#### 交互规则


| #   | 规则项  | 规则说明                          |
| --- | ---- | ----------------------------- |
| 1   | 勾选效果 | 用户勾选"记住密码"并登录成功后，浏览器保存账号和密码信息 |
| 2   | 回填规则 | 下次进入登录页时，若存在已保存信息，则自动回填账号和密码  |
| 3   | 取消勾选 | 用户取消勾选并登录成功后，清除本地已保存的账号和密码    |


### 2.6 个人中心微信绑定与解绑

#### 功能说明

在登录页已支持微信扫码登录与账号绑定的基础上，个人中心需补充微信绑定状态管理能力，支持教师在已登录状态下通过个人中心查看微信绑定状态、扫码绑定微信，以及解除已绑定的微信账号。

#### 交互说明


| #   | 交互项   | 说明                             |
| --- | ----- | ------------------------------ |
| 1   | 入口位置  | 个人中心“个人信息”区域新增“微信绑定”字段         |
| 2   | 未绑定状态 | 展示“未绑定”文案，并显示“绑定”按钮            |
| 3   | 绑定方式  | 点击“绑定”后弹出二维码窗口，用户使用微信扫一扫完成绑定   |
| 4   | 绑定成功  | 扫码绑定成功后，状态更新为“已绑定”，操作按钮切换为“解绑” |
| 5   | 已绑定状态 | 展示“已绑定”文案，并显示“解绑”按钮            |
| 6   | 解绑方式  | 点击“解绑”后弹出密码验证弹窗                |
| 7   | 密码校验  | 用户需输入当前登录账号密码，校验通过后才允许解绑       |
| 8   | 解绑成功  | 解绑成功后，状态更新为“未绑定”，操作按钮切换为“绑定”   |
