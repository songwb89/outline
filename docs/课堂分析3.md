将课堂录音/视频自动转成带角色标注的文字稿，方便后续分析学生学习情况。

## 实现步骤

### 步骤18：生成性教学内容

#### 18.1 功能描述

**做什么**：基于教案文本和课堂对话内容，识别并提取课堂中由教师即兴发挥、临时拓展或超出教案预设的生成性教学内容，按课堂主环节归类呈现，并给出整体分析点评。

本功能用于回答以下问题：

1. 课堂中哪些内容是教师在教案之外临时生成、发挥或拓展的
2. 这些生成性内容分布在哪些教学环节，各自有什么特点
3. 整体来看，生成性内容的占比和质量如何，有哪些值得肯定或需要改进的地方

**生成性内容的定义**：相对于教案中预设的教学内容而言，课堂中教师临时引出的内容，包括即时补充的典故/例子、生活化类比、跨文本关联、追问延伸、情感升华引导、课堂管理中的即兴互动等。

**数据来源**：

1. 步骤16中教案处理流程输出的教案文本
2. 步骤17.3执行环节生成规则输出的执行环节数组（含主环节名称及对应的课堂对话内容）

**处理流程**：

```
教案文本（步骤16输出）+ 执行环节数组（步骤17.3输出，含主环节 + 对话内容）
    ↓
程序将教案文本与执行环节数组同时传给模型（一次调用）
    ↓
模型按主环节逐个分析，对照教案提取课堂中教案未涉及的内容
    ↓
输出每个主环节下的生成性内容数组 + 整体分析点评
```

#### 18.2 AI 识别规则

系统将教案文本和执行环节数组同时输入模型，由模型基于对话内容逐环节分析，识别出教案预设之外教师生成的临场内容。

**识别目标**：

- 识别教案文本中未涵盖、但在课堂对话中实际出现的内容
- 识别不属于该环节预设教学内容，但教师主动引出的延伸、拓展或追问
- 不识别教案中已有、仅由教师重复或照本宣科的内容

**识别原则**：

1. 以课堂主环节为单位逐个分析，不遗漏任一主环节
2. 生成性内容的标题应简洁概括该内容的核心特征，4~10字
3. 生成性内容的描述应说明"教案中是否有/是否有提及"以及"课堂上具体发生了什么"，10~100字
4. 若某主环节下没有生成性内容，则该环节对应数组为空，不输出占位
5. 生成性内容的描述优先采用"教案中未提及/教案中无相关内容，课堂上教师……"的表达方式

**字段说明**：

| items | array | AI模型生成 | 该环节下的生成性内容数组 |
| title | string | AI模型生成 | 生成性内容标题，4~10字 |
| description | string | AI模型生成 | 生成性内容描述，说明教案中是否有、课堂上具体发生了什么 |
| ai_analysis | object | AI模型生成 | 对整堂课生成性教学情况的总体分析 |
| ai_analysis.comment | string | AI模型生成 | 对生成性教学内容的点评 |
| ai_analysis.suggestion | string | AI模型生成 | 对生成性教学优化的建议 |

**约定说明**：

- 仅输出有生成性内容的主环节；没有生成性内容的主环节不输出
- `items` 数组长度至少为 1
- 生成性内容必须源于课堂对话的客观事实，不得凭空捏造或过度推断
- `ai_analysis.suggestion` 至少包含 1 条具体建议，建议条数不限

#### 18.4 AI 提示词

##### 18.4.1 生成性内容识别提示词

###### 系统提示词

```
你是一个专业的教学分析助手。

【核心任务】
对比教案文本与课堂实际对话内容，识别并提取课堂中由教师即兴发挥、临时拓展或超出教案预设的生成性教学内容，按课堂主环节归类，一次性输出完整结果。

【输入数据说明】
输入包含两部分：

1. lesson_plan_text：教案原文，代表教学设计中的预设内容
2. execution_phases：执行环节数组，代表课堂实际发生的教学过程
   - name：课堂主环节名称
   - transcript：该主环节对应的课堂对话内容（含教师话语和学生话语）

【输出格式】（严格遵守）
{
  "phase_generated_content": [
    {
      "phase_name": "主环节名称",
      "items": [
        {
          "title": "生成性内容标题，4~10字",
          "description": "说明教案中是否有相关内容，以及课堂上具体发生了什么，10~100字"
        }
      ]
    }
  ],
  "ai_analysis": {
    "comment": "对整堂课生成性教学情况的整体点评，30~150字",
    "suggestion": "对生成性教学的优化建议，至少1条，每条30~100字"
  }
}

【识别规则】
1. 逐个分析每个主环节，对照教案与对话内容，识别教案中未涵盖的临场生成内容
2. 生成性内容的标题应简洁概括该内容的核心特征，4~10字
3. 生成性内容的描述应说明教案中是否有相关内容，以及课堂上具体发生了什么，10~100字
4. 生成性内容的描述优先采用"教案中未提及……，课堂上教师……"的表达方式
5. 仅输出有生成性内容的主环节，没有生成性内容的主环节不输出
6. 生成的 items 顺序按课堂时间顺序排列
7. ai_analysis.comment 应说明生成性内容的整体情况和质量评价
8. ai_analysis.suggestion 应给出至少1条具体可操作的改进建议
9. 不要输出除 JSON 外的任何内容
```
